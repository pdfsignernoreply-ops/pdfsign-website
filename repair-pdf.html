Why PDFs get rejected

Portals like GeM run a strict, older PDF reader. Files saved by online tools, scanners and some merge apps use a structure it can't open — even though Adobe and Chrome read them fine.

🧩

Invalid PDF structure

Object streams and compressed cross-references the portal's uploader can't parse.

🔗

Broken cross-references

A damaged xref table that makes the file look corrupt on upload.

🏷️

Corrupted metadata

Leftover author/software data and edit history that trips validation.

📄

Unsupported PDF version

A newer save format the portal's parser doesn't fully support.

🌐

Issues from online editors

Web converters and compressors save with structures GeM rejects by default.

FAQ

Why does GeM say "File type not supported" for a valid PDF?

The file was saved in a compressed internal structure GeM's older uploader can't read — common with PDFs from online converters, scanners and merge tools. Repairing it rewrites the file into the classic structure GeM accepts.

Does re-saving in Adobe fix it?

Usually not — Adobe often writes the file back out the same way, so the portal keeps rejecting it. Use a repair tool that rebuilds the cross-reference structure.

Is it safe to repair my bid documents?

Yes. PDFSign repairs entirely on your PC — your documents are never uploaded to any server.
