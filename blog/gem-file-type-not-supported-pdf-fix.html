FAQ

Why does GeM say "File type not supported" for a valid PDF?

The file was saved in a compressed internal structure that GeM's older uploader can't read — common with PDFs from online converters, scanners and merge tools. Repairing it rewrites the file into the classic structure GeM accepts.

Does re-saving in Adobe fix it?

Usually not — Adobe often writes the file back out the same way, so GeM keeps rejecting it. Use a repair tool that rebuilds the cross-reference structure.
