Changelog

Release history for PDFSign — current version v3.8.2, released 3 September 2026

v3.8.2 September 2026
  • Fixed: signing failed on PDFs that had been signed once before — if you saw a ByteRange error, this release clears it
  • Compress now shrinks text-only and scan-style PDFs that previously would not compress at all, and size estimates are much faster
  • Convert to Word now produces real, editable text from scanned and image-based PDFs instead of a picture inside a Word file
  • PDF Toolbox opens with Edit PDF, Convert to Word, Merge and Compress up front, plus a search box to find any tool
  • Right-click any PDF in File Explorer to open it straight in Edit PDF
  • New guided tour for first-time users
v3.8.1 August 2026
  • Buy and unlock inside the app — pay, and PDFSign activates itself, with no licence key to type
  • Restore your licence on a new PC using just your email address
  • Files signed with an all-pages stamp are now dramatically smaller
  • Edit PDF works on every install type, handles rotated pages, and adds Hindi text support
  • Clearer activation screen
  • New Enterprise plan with AutoSign
v3.7.3 July 2026
  • Signing no longer stalls when a timestamp server is slow or you are offline — PDFSign completes a valid digital signature either way, skipping the timestamp when it cannot be reached
  • The Government/Adobe signature style is now applied correctly when placing signatures page by page
  • First-run welcome guidance for new installs
v3.7.2 July 2026
  • PDF Toolbox — merge, split, compress and convert PDFs alongside signing, all on your own PC
  • Right-click a PDF in File Explorer and open it directly with PDFSign
v3.7.1 July 2026
  • Activation now completes in the same session — no need to restart the app after buying
  • Restored the classic navy PDFSign logo across the app
v3.7.0 July 2026
  • Signing is roughly 7× faster — removed an online certificate-revocation lookup that was adding 10–20 seconds to every file
  • PAdES is now the default signature standard (recommended)
  • Set signature positions page by page without first saving a template, with previews and click-to-place at your configured size
  • Free evaluation limits stated plainly in the app: up to 30 days or 100 signed PDFs
  • More reliable crash reporting
v3.6.5 June 2026
  • New Government/Adobe-style signature stamp, now the default — the familiar "Signature valid" look government portals and officers expect
  • Redesigned signing-success screen showing your signing stats and a privacy reminder
  • RFC 3161 timestamp is always visible; advanced security options tucked away to reduce clutter
  • The app now opens maximised for a cleaner one-screen view
v3.6.3 June 2026
  • Smarter certificate selection — auto-detects your connected DSC token without asking for a PIN, listed alphabetically
  • Prevents an invalid output file being written if the token is unplugged part-way through
  • In-app demo and interface polish
v3.6.2 June 2026
  • Fixed GeM and other portal upload compatibility for signed PDFs
  • Added a first-run guide
  • Improved the in-app update experience
v3.3.2 May 2026
  • "Click to Place Signature" is now the default placement mode for easier signing
v3.0.0 – v3.2.0 April – May 2026
  • PDFSign 3 — DSC token signing, signature and stamp images, bulk signing, click-to-place positioning, RFC 3161 timestamping and PDF security in a single app
  • PDFSign now installs from the Microsoft Store — one-click install, a Microsoft-verified publisher, and automatic updates
v2.1.0 March 2026
  • Added support for HyperPKI HYP2003 token auto-detection
  • Improved batch signing speed by 40%
  • Fixed PIN dialog not appearing on some Windows 11 configurations
  • Added signature position preview in the UI
  • Updated iText7 to latest version for improved PAdES compliance
v2.0.0 January 2026
  • Complete UI redesign — lighter, faster, and easier to use
  • Added Folder/Batch signing mode
  • Online licence activation and management
  • Razorpay payment integration
  • Auto-update mechanism added
  • 30-day free trial introduced
v1.2.0 September 2025
  • Added support for Proxkey and eMudhra tokens
  • Signature stamp appearance customisation
  • Bug fix: signed PDF losing metadata on some documents
v1.0.0 June 2025
  • Initial public release
  • Single file PDF signing with DSC token
  • Support for ePass 2003 and ePass 3003
  • PAdES compliant signatures
